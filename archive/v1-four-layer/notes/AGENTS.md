# AGENTS.md

本文件面向在本工作区工作的 AI 代理，描述 `notes/`（课堂笔记）模块的结构与约定。上级项目说明见 `../README.md`。

## 项目概述

这是一个纯 Markdown 课堂笔记库的一部分。本工作区对应 `notes/` 目录，职责是**记录课堂笔记**；概念定义统一放在 `../glossary/`，资料溯源放在 `../references/`，导航入口为 `../index.md`。

设计原则：

- 单一事实来源：术语定义只写在 `glossary/`，笔记中只链接，不重复抄写。
- 纯文本：公式用 LaTeX（`$...$` / `$$...$$`），流程图用 Mermaid，不用二进制附件。
- 可增量维护：课上允许只写要点，课后补全。

## 目录结构

```
notes/
├── index.md                    # 笔记索引（按日期 / 课程），新笔记必须登记
├── AGENTS.md                   # 本文件
└── YYYY-MM-DD-主题.md          # 笔记文件
```

相关外部目录（使用相对路径 `../` 引用）：`../glossary/`、`../references/`、`../templates/note.md`（新建笔记的模板）、`../index.md`（总索引）。

## 命名规范

- 笔记文件：`YYYY-MM-DD-主题.md`，用 `-` 连接，不含空格，避免 `\ / : * ? " < > |`。
- 同一主题的多次课按日期区分，**不要覆盖旧文件**。

## 笔记文件约定

### Front Matter（YAML，文件开头）

```yaml
---
title: 线性回归
course: 机器学习
date: 2026-11-12
instructor: 教师名
tags: [回归, 最小二乘]
status: 已整理
---
```

`status` 只有三档：`草稿`（课上速记）、`已整理`（课后补全）、`已复习`（已通读确认）。

### 固定章节

一篇整理完成的笔记应包含：本节要点、正文、课堂强调、疑问与待办（任务列表 `- [ ]`）、**相关术语**、**参考来源**、修订记录（日期 + 修改内容的表格）。

### 交叉链接写法

| 引用目标 | 写法 |
| --- | --- |
| 术语 | `[梯度下降](../glossary/梯度下降.md)` |
| 资料 | `[周志华 2016](../references/教材-周志华-2016-机器学习.md)` |
| 其他笔记 | `[上一讲](2026-11-05-决策树.md)` |
| 返回索引 | `[返回笔记索引](index.md)` |

术语链接和资料链接集中在笔记底部的「相关术语」「参考来源」两节，避免散落正文。

## 索引维护（重要）

新建或修改笔记后，必须同步更新 `index.md`：

1. 在「全部笔记」表格**顶部插入一行**：日期、课程、主题（链接到笔记文件）、状态、关联术语。
2. 在对应课程的「按课程」表格中也登记一行。
3. 状态有变化（草稿 → 已整理 → 已复习）时，同步更新索引中的状态列。
4. 已解决的待办可移入索引底部「待补内容」的勾选列表并勾选。

## 代理工作流程

新建一篇笔记时：

1. 复制 `../templates/note.md`（或参照现有笔记如 `2026-11-12-示例笔记.md`）到本目录。
2. 按命名规范重命名，填写 Front Matter。
3. 正文公式用 `$...$`（行内）和 `$$...$$`（独立），流程用 Mermaid。
4. 出现的新术语 → 在 `../glossary/` 建条目并从笔记链接过去（不要在笔记里写定义）。
5. 用到的资料 → 登记/链接到 `../references/`。
6. 更新 `index.md` 登记。
7. 更新笔记底部「修订记录」。

修改既有笔记时：保持原章节结构，追加而非重排；完成后更新 `status`、`index.md` 与修订记录。

## 编码与格式

- 全部文件 UTF-8 无 BOM。
- Markdown 风格与现有文件保持一致：ATX 标题（`##`）、管道表格、任务列表用 `- [ ]`。
- 不要在笔记中引入 HTML、图片二进制或专有格式；图表一律 Mermaid。
