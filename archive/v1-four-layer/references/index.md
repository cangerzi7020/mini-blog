## 登记规则

| 项目 | 要求 |
| --- | --- |
| 编号 | `R` + 三位序号，按登记顺序递增，不复用 |
| 标题 | 保留原始标题，不自行改写 |
| 链接 | 网页资料记录访问日期，链接优先用永久地址 |
| 用途 | 说明这份资料是被用来核对什么，而不只写「参考」 |
| 关联 | 指向使用它的笔记，形成双向索引 |

## 引用格式

在笔记中引用资料时，统一写成「标题 + 年份 + 链接」：

```markdown
参考文献第 3 章（[示例教材, 2026](../references/index.md)）
```
